# Campus Course Management System

## Project Overview

The Campus Course Management System is a web-based application designed to provide a centralized platform for students to access course information, manage their academic activities, and receive important notifications.

The system aims to simplify course management and provide students with an easy-to-use interface for accessing academic information.

---

## Problem Statement

Managing course information, student details, registrations, and academic notifications manually can be time-consuming and difficult to maintain.

Students may also find it difficult to access updated course information from different sources.

The Campus Course Management System provides a centralized platform where students can register, log in, view their dashboard, access available courses, and receive notifications.

---

## Objectives

* Provide a centralized platform for course management.
* Allow students to register and log in.
* Display student information through a dashboard.
* Display available courses.
* Provide academic notifications.
* Create a responsive and user-friendly interface.
* Maintain a structured and scalable project architecture.

---

## Target Users

### Students

Students can:

* Register for an account.
* Log in to the system.
* View their student information.
* View available courses.
* View notifications.
* Access the student dashboard.

### Faculty

Faculty members can later use the system to:

* Manage courses.
* Upload course materials.
* View enrolled students.
* Publish academic information.

### Administrator

Administrators can later:

* Manage students.
* Manage faculty.
* Manage courses.
* Manage notifications.

## How to Run the Project

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

Open the project folder in Visual Studio Code.

### 3. Open the Home Page

Navigate to:

```text
frontend/html/index.html
```

Open `index.html` in a web browser.

You can also use the **Live Server** extension in Visual Studio Code.
